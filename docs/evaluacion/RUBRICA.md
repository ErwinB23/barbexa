
# Rúbrica de evaluación — App Barbería

Fuente: rúbrica proporcionada por el docente de Arquitectura de Software.

## Criterios técnicos (1–13)

1. Identificación del problema y requerimientos.
2. Análisis y diseño del sistema.
3. Arquitectura de bajo y alto nivel.
4. Desarrollo basado en SDD (Spec-Driven Development).
5. Pruebas unitarias e integración.
6. Pruebas End to End.
7. Interfaz y experiencia de usuario.
8. Escalabilidad del frontend y backend.
9. Escalabilidad de base de datos.
10. Configuración de dominio y/o subdominio, DNS y CDN.
11. Implementación de caché.
12. CI/CD.
13. Pruebas de carga k6.

## Criterios de entrega (14–16)

14. Código fuente y base de datos en GitHub.
15. Informe final.
16. Presentación y dominio del tema.

## Seguimiento

Cada criterio debe relacionarse con:
- Requisitos y decisiones arquitectónicas.
- Especificaciones y tareas de implementación.
- Pruebas y evidencias verificables.
- Estado: pendiente, en desarrollo, implementado o validado.

No declarar un criterio como validado sin evidencia.
