regresiones arquitectónicas y después las unitarias, con &&; check ejecuta los controles
en orden y se detiene al primer fallo. start usa expo start --go --lan. No se arrancó
Metro ni se simuló un recorrido móvil: aún no hay rutas.

.gitignore excluye node_modules, .expo, .test-build, .artifacts, cobertura, dist/build,
expo-env.d.ts, tsbuildinfo y variables locales; las evidencias no se ocultan.
package-lock.json y versiones de dependencias permanecen sin cambios.

T013: únicamente cuatro archivos bajo src/shared/ui. Tokens de paleta aprobada, tipografía
del sistema 14/16/24, escala de espacio 4–32, radios 8/12. AppText permite escalado sin
tope ni truncamiento impuesto; títulos con rol header. AppButton ofrece label accesible,
rol button, disabled anunciado, foco/pulsación visibles y dimensiones mínimas 48×48 dp,
con altura adaptable. Screen usa scroll, zonas seguras y ancho limitado para futuras
plataformas. El SafeAreaProvider será responsabilidad de la composición en T014.

real todavía requieren inspección en Android; no se acredita SC-005.
