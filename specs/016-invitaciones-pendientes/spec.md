# 016 — Invitaciones pendientes

Desplegables separados Pendientes e Historial de invitaciones. Pendientes muestra
nombre actual de cuenta, correo y fecha de envío de Lima, más recientes primero,
sin duplicación con historial y sin datos inventados. Conserva cancelar e incorpora
Reenviar. El usuario eligió expresamente aviso dentro de BARBEXA, no correo.

Solo administrador activo de la barbería puede leer correo o reenviar una invitación
profesional pendiente de ese local. Reenviar exige además el permiso existente de
Gestión de equipo (propietario), sin concederlo a administradores secundarios.
No altera estado, fecha o roles de invitación.
Recordatorio en bandeja existente, sin envío externo. Exclusión concurrente y ventana
mínima de60s por invitación para evitar duplicados por pulsaciones/reintentos.
Error/carga/éxito y resultado de aviso reciente explícitos. Datos compartidos Android.

Cloud y ensayo SQL activados con autorización específica el 23/11/2026; recorrido
funcional manual Web aceptado el 24/11/2026. Android y la comprobación específica
de reenvío/destinatario de tasks.md no se infieren de esa aceptación. Nuevas
escrituras o envíos requieren autorización; 015 no concede permisos adicionales.
